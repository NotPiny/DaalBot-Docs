This command allows users to quickly delete many messages at a time.

## /purge
<Command>
    <div slot="usage">
        To purge messages within a channel simply run the command and specify the amount of messages, it will then delete the specified amount of messages in the channel.
    </div>
    <div slot="params">
        <ParamTable input={{
            amount: {
                description: "The amount of messages to delete",
                type: "Number",
                required: true
            }
        }} />
    </div>
    <div slot="examples">
        * `/purge amount:50` - Deletes the last 50 messages within the current channel
    </div>
    <div slot="permissions">
        Both you and the bot need the `Manage Messages` permission for this command to work.
    </div>
</Command>
