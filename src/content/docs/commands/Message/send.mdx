This command allows server administrators to send messages to specific channels within their guild. Users can specify the channel, and message content.
## /send
This command allows users to send a message to a specified channel.
<Command>
    <div slot="usage">
        Use the command followed by the channel and message.
    </div>
    <div slot="params">
        <ParamTable input={{
            channel: {
                description: "The channel to send the message in.",
                type: "Channel",
                required: true,
                choices: "Text Channel, Announcement Channel"
            },
            text: {
                description: "The message to send in the specified channel.",
                type: "String",
                required: true
            }
        }} />
    </div>
    <div slot="examples">
        * `/send channel:#general text:Hello everyone!` - Sends "Hello everyone!" to the #general channel.
        * `/send channel:#announcements text:Don't forget to check out our latest updates!` - Sends the announcement message to the #announcements channel.
    </div>
    <div slot="permissions">
        * Users need the "Send Messages" permission in the specified channel to use this command.
        * The bot needs the "Send Messages" permission in the specified channel to send messages.
    </div>
</Command>
