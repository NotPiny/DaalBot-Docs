This command allows server administrators to create self-assignable role messages within their guild. Users can set up messages with buttons or dropdown menus that members can interact with to assign or remove roles from themselves.

<Aside type="danger">
This command hasn't been migrated to use Discord Components V2 yet, so it does have a risk of breaking newer features. Use with caution.
</Aside>
<Aside type="caution">
Assigning roles to members requires DaalBot to have the appropriate permissions to manage roles in the server. Ensure that DaalBot's role is higher than the roles it needs to assign in the role hierarchy. If you are unsure on what this means, you can usually just drag DaalBot's role to the top of the role list in your server settings and we'll handle the rest.
</Aside>
<Aside type="tip">
Self assigned roles are supported in other features such as Components V2 message builders through their custom IDs. For information on how to do this, refer to the [Components V2 message builder documentation](/features/dashboard/message-builder).
</Aside>

## /selfrole button
This command allows users to create or append a role button to an existing message. Members can click the button to assign or remove the specified role.
<Command>
    <div slot="usage">
        Use the command followed by the role, channel, message link, and optional parameters.
    </div>
    <div slot="params">
        <ParamTable input={{
            role: {
                description: "The role to link to the button.",
                type: "Role",
                required: true
            },
            channel: {
                description: "The channel the message is in.",
                type: "Channel",
                required: true,
                choices: "Text Channel, Announcement Channel"
            },
            message_link: {
                description: "The message link to add the button to.",
                type: "String",
                required: true
            },
            label: {
                description: "The label text for the button.",
                type: "String",
                required: false
            },
            emoji: {
                description: "The emoji to add to the button.",
                type: "String",
                required: false
            },
            style: {
                description: "The style of the button.",
                type: "String",
                required: false,
                choices: "Primary (Blue), Secondary (Grey), Success (Green), Danger (Red)"
            }
        }} />
    </div>
    <div slot="examples">
        * `/selfrole button role:@Gamer channel:#roles message_link:https://discord.com/channels/123456789012345678/234567890123456789/345678901234567890 label:Join Gamer emoji:🎮 style:Primary` - Adds a primary button to the specified message that assigns the "Gamer" role.
    </div>
</Command>

## /selfrole dropdown
This command allows users to create or append a role dropdown menu to an existing message. Members can select roles from the dropdown to assign or remove them from themselves.
<Command>
    <div slot="usage">
        Use the command followed by the role, channel, message link, and optional parameters.
    </div>
    <div slot="params">
        <ParamTable input={{
            role: {
                description: "The role to add to the dropdown.",
                type: "Role",
                required: true
            },
            channel: {
                description: "The channel to send the dropdown to.",
                type: "Channel",
                required: true,
                choices: "Text Channel, Announcement Channel"
            },
            message_link: {
                description: "The message link to add the menu to.",
                type: "String",
                required: true
            },
            placeholder: {
                description: "The placeholder text for the dropdown.",
                type: "String",
                required: false
            }
        }} />
    </div>
    <div slot="examples">
        * `/selfrole dropdown role:@Gamer channel:#roles message_link:https://discord.com/channels/123456789012345678/234567890123456789/345678901234567890 placeholder:Select your roles` - Adds a dropdown menu to the specified message with the "Gamer" role as an option.
    </div>
</Command>
