This command allows server administrators to manage events or automated actions within their server. Users can create, edit, delete, and list events that trigger specific actions based on defined conditions.

## /event create
This command allows users to create a new event that triggers specific actions based on defined conditions. Users can specify the event type and configure its settings.
<Command>
    <div slot="usage">
        Use the command followed by the event type you want to create.
    </div>
    <div slot="params">
        <ParamTable input={{
            trigger: {
                description: "The type of event to create.",
                type: "String",
                required: true,
                choices: "Message Create, Message Update, Message Delete, Channel Create, Channel Update, Channel Delete, Guild Update, Guild Ban Add, Guild Ban Remove, Guild Member Add, Guild Member Remove, Guild Member Update, Guild Role Create, Guild Role Update, Guild Role Remove, Message Reaction Add, Message Reaction Remove, Interaction Create, Voice State Update, Guild Warn Create, Guild Warn Delete"
            }
        }} />
    </div>
    <div slot="examples">
        * `/event create trigger:Message Create` - Creates a new event that triggers on message creation.
    </div>
    <div slot="permissions">
        * Users need the "Manage Server" permission to use this command.
    </div>
</Command>

<Aside>
Once this command is run you will be prompted to enter the name and description for the event. After that you can edit the code for the event in the [dashboard](https://dashboard.daalbot.xyz/). To learn more about events and how to use them, visit our [Events](/features/events/overview) documentation.
</Aside>

## /event list
This command allows users to list all events in the server. It displays the event names, descriptions, triggers, and IDs.
<Command>
    <div slot="usage">
        Use the command to list all events in the server. You can optionally filter by event trigger type.
    </div>
    <div slot="params">
        <ParamTable input={{
            trigger: {
                description: "The type of event to filter by.",
                type: "String",
                required: false,
                choices: "Message Create, Message Update, Message Delete, Channel Create, Channel Update, Channel Delete, Guild Update, Guild Ban Add, Guild Ban Remove, Guild Member Add, Guild Member Remove, Guild Member Update, Guild Role Create, Guild Role Update, Guild Role Remove, Message Reaction Add, Message Reaction Remove, Interaction Create, Voice State Update, Guild Warn Create, Guild Warn Delete"
            }
        }} />
    </div>
    <div slot="examples">
        * `/event list` - Lists all events in the server.
        * `/event list trigger:Message Create` - Lists all events that trigger on message creation.
    </div>
    <div slot="permissions">
        * Users need the "Manage Server" permission to use this command.
    </div>
</Command>

<Aside type="caution">
Due to potential security risks, imported events should be reviewed and edited as necessary to ensure they function as intended within your server's context. Imported events do not automatically update if the original event is changed.
</Aside>
