<Aside type="caution">
Verification is a legacy module and is no longer actively maintained. You should instead be using Discord's built-in onboarding system for new members.
</Aside>

The verification module within DaalBot provides server administrators with tools to help ensure that members have read the rules before gaining full access to the server.

## Setup
To set up verification, you can use the `/verify` command. Documentation for this command can be found here: [Verify Command Documentation](/commands/guild/verify).
When you run the `/verify` command, DaalBot will guide you through the process of setting up verification for your server.
